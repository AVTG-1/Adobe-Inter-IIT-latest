Development Process

Backend Development

# Start backend with hot reload
uvicorn app.orchestration.application.main:app --reload

# Run tests
pytest tests/

# Format code
black app/
ruff check app/

Frontend Development

# Start Expo dev server
npm start

# Run on Android
npm run android

# Run on iOS
npm run ios

# Type checking
npx tsc --noEmit

Code Organization

  • Backend: 3-layer architecture (Orchestration, Core, Experts)
  • Frontend: Component-based with service layer
  • Types: Full TypeScript coverage on frontend
  • API: RESTful + WebSocket protocols
