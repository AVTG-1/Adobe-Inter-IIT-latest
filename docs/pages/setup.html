Setup & Installation Guide

Complete setup instructions for backend and frontend development

Prerequisites

🐍

Backend

  • Python 3.10+
  • pip (Python package manager)
  • Docker (for Imaginary service)
  • Google Cloud SDK (optional)
📱

Frontend

  • Node.js 20.0.0+
  • npm 10.0.0+
  • Expo CLI
  • Android Studio / Xcode
🔑

API Keys

  • Google Gemini API key
  • Firebase project (optional)
  • GCS service account (optional)

Backend Setup

1. Clone Repository

git clone https://github.com/your-repo/Adobe-Frontend-Inter-IIT.git
cd Adobe-Frontend-Inter-IIT

2. Install Python Dependencies

pip install -r requirements.txt

Key Dependencies:

Package Version Purpose
fastapi 0.104.1 Web framework for API
google-generativeai ≥0.3.0 Gemini LLM integration
torch ≥2.0.0 Deep learning framework
pillow ≥10.0.0 Image processing
google-cloud-storage ≥2.10.0 GCS integration

3. Set Up Imaginary Service

Imaginary is the image processing microservice required for edit operations.

💡 Recommended: Use Docker for easiest setup. 
# Pull and run Imaginary container
docker run -d -p 8080:9000 \
  --name imaginary \
  h2non/imaginary:latest \
  -enable-url-source

# Verify it's running
curl http://localhost:8080/info

4. Configure Environment Variables

# Copy example environment file
cp .env.example .env

# Edit .env with your settings
nano .env

Minimum Configuration:

# Imaginary API (REQUIRED)
IMAGINARY_BASE_URL=http://localhost:8080
IMAGINARY_TIMEOUT=30

# Gemini API (REQUIRED for AI features)
GEMINI_API_KEY=your_gemini_api_key_here

# Storage (Choose one)
LOCAL_STORAGE_PATH=./storage
# OR
# CLOUD_STORAGE_BUCKET=your-gcs-bucket-name
# GOOGLE_APPLICATION_CREDENTIALS=/path/to/credentials.json

5. Set Up Storage

Option A: Local Storage (Development)

# Create storage directory
mkdir -p storage
chmod 755 storage

# No additional configuration needed!

Option B: Google Cloud Storage (Production)

# Install Google Cloud SDK
curl https://sdk.cloud.google.com | bash
exec -l $SHELL

# Initialize and authenticate
gcloud init
gcloud auth application-default login

# Create GCS bucket
gsutil mb -p YOUR_PROJECT_ID -l us-central1 gs://your-bucket-name

# Set environment variable
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account.json"

6. Start Backend Server

# Option 1: Using run script
./run.sh

# Option 2: Using uvicorn directly
uvicorn app.orchestration.application.main:app --reload --host 0.0.0.0 --port 8000

# Server will be available at:
# http://localhost:8000
# API docs: http://localhost:8000/docs
✓ Backend Ready! Visit http://localhost:8000/docs to test the API.

Frontend Setup

1. Navigate to Frontend Directory

cd frontend

2. Install Dependencies

npm install

# If you encounter peer dependency issues:
npm install --legacy-peer-deps

Key Dependencies:

Package Version Purpose
expo ~54.0.23 React Native framework
react-native 0.81.5 Mobile app framework
@react-navigation ^7.x Navigation library
axios ^1.13.2 HTTP client
@gorhom/bottom-sheet ^5.2.6 Bottom sheet UI

3. Configure Firebase (Optional)

Firebase is used for cloud image storage in the mobile app.

# Create src/config/firebase.ts with your credentials
export const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};

4. Configure Backend URL

# Edit src/config/index.ts
export const API_CONFIG = {
  BASE_URL: 'http://localhost:8000',  // Or your server IP
  TIMEOUT: 30000,
  MOCK_MODE: false  // Set to true for offline development
};

5. Start Development Server

# Start Expo
npm start

# Or specific platform
npm run android  # Android emulator/device
npm run ios      # iOS simulator (Mac only)
npm run web      # Web browser
⚠️ Network Configuration: For Android device/emulator to reach backend on localhost, you may need to use your computer's IP address instead of localhost.

Development Tools Setup

Android Studio (For Android Development)

  1. Download Android Studio from developer.android.com/studio
  2. Install Android SDK and emulator
  3. Set up environment variables: 
    export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
  4. Create a virtual device (AVD) with API 33+

Xcode (For iOS Development - Mac Only)

  1. Install Xcode from App Store
  2. Install Xcode Command Line Tools: 
    xcode-select --install
  3. Install CocoaPods: 
    sudo gem install cocoapods

Troubleshooting

Backend Issues

Issue: "Connection refused" to Imaginary

Solution:

# Check if Imaginary is running
docker ps | grep imaginary
curl http://localhost:8080/info

# Restart if needed
docker restart imaginary

Issue: "ModuleNotFoundError" for Python packages

Solution:

# Ensure you're using correct Python version
python --version  # Should be 3.10+

# Reinstall dependencies
pip install -r requirements.txt --upgrade

Issue: GCS authentication errors

Solution:

# Verify credentials path
echo $GOOGLE_APPLICATION_CREDENTIALS

# Test authentication
gcloud auth application-default login

# Check service account permissions
gcloud projects get-iam-policy YOUR_PROJECT_ID

Frontend Issues

Issue: "Unable to resolve module"

Solution:

# Clear Metro bundler cache
npm start -- --clear

# Or delete node_modules and reinstall
rm -rf node_modules package-lock.json
npm install

Issue: "Network request failed"

Solution:

  • Use your computer's IP address instead of localhost
  • Ensure backend server is running and accessible
  • Check firewall settings
# Find your IP address
# Mac/Linux:
ifconfig | grep "inet "
# Windows:
ipconfig

# Update config to use IP
BASE_URL: 'http://192.168.1.100:8000'

Issue: Expo "JavaScript heap out of memory"

Solution:

# Increase Node.js memory limit
export NODE_OPTIONS="--max-old-space-size=4096"
npm start

Quick Start (All-in-One)

For the fastest setup with minimal configuration:

# Backend (Terminal 1)
pip install -r requirements.txt
docker run -d -p 8080:9000 --name imaginary h2non/imaginary:latest -enable-url-source
echo "IMAGINARY_BASE_URL=http://localhost:8080" > .env
echo "LOCAL_STORAGE_PATH=./storage" >> .env
echo "GEMINI_API_KEY=your_key_here" >> .env
./run.sh

# Frontend (Terminal 2)
cd frontend
npm install
npm start
🎉 Done! Your development environment is ready. Check out the Development Workflow guide to start building.
