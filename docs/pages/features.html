Drawing & Annotation

Drawing Tools (13 Total)

  • Pen - Smooth drawing with pressure sensitivity
  • Brush - Soft artistic brush
  • Highlighter - Semi-transparent marker
  • Marker - Bold, opaque strokes
  • Eraser - Remove drawn elements
  • Rectangle - Draw rectangular shapes
  • Circle - Perfect circles and ellipses
  • Triangle - Triangular shapes
  • Arrow - Directional arrows
  • Line - Straight lines
  • Star - Star shapes
  • Heart - Heart shapes
  • Text - Add text annotations

Drawing Features

  • 10 preset colors + color picker
  • Size control (2-50px)
  • Opacity control (0-100%)
  • Undo/redo for drawing
  • Clear all drawings
  • Layer-based drawing system

Geometric Transformations

Crop Tool

  • Aspect Ratios: Free, 1:1, 4:3, 3:4, 16:9, 9:16
  • Shape Crop: Circle, heart, star shapes
  • Interactive Handles: Drag corners to adjust
  • Grid Overlay: Rule of thirds guide
  • Reset Button: Restore original

Rotate & Flip

  • Rotate 90°, 180°, 270°
  • Free rotation with angle slider
  • Flip horizontal
  • Flip vertical

Resize Tool

  • Preset dimensions (Instagram, YouTube, etc.)
  • Custom width × height
  • Maintain aspect ratio option
  • Percentage-based scaling

AI-Powered Features

Natural Language Editing

User: "Make this photo more vibrant and add a warm filter"

AI Plans:
1. Increase saturation +30%
2. Increase vibrance +20%
3. Apply warm color filter
4. Adjust temperature +15

Executes automatically with WebSocket updates

Intelligent Workflows

  • Multi-Step Planning: LLM generates editing sequences
  • Context-Aware: Analyzes image content
  • Self-Healing: Automatic error recovery
  • Real-Time Feedback: Step-by-step progress

Tree-Based History

  • Non-linear editing with branching
  • Switch between versions instantly
  • Refine any step to create new branch
  • Visual tree navigation
  • Macro recording from paths

Layer System

  • Multiple Layers: Add unlimited layers
  • Layer Types: Image, drawing, text, shape
  • Layer Controls: Visibility, opacity, delete, duplicate
  • Reordering: Drag to reorder (planned)
  • Blending: Layer blend modes (planned)
  • Merge: Flatten layers
